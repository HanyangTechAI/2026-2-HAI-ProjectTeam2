# stylematch 실험 기록 (Step 3, 2026-11-24 ~ 11-25)

같은 연주의 dry가 없는 실제 사용 조건에서 "내 페달로 목표 톤에 가장 가깝게" 만드는 방법을 찾은 기록.
수치는 모두 이 저장소 코드로 재현 가능 (명령은 [README.md](README.md)).

## 1. 문제: 같은 연주 쌍 전제가 실제 사용에서 깨짐

- Step 1·2 시스템(CNN + 시점별 거리 d + CMA-ES)은 **같은 연주의 dry/wet 쌍**으로 설계·학습·검증됨 → 처음 보는 기타에서도 최종 95.4% (Step 2).
- 실제 사용 = 곡 음원(목표) + 사용자의 **다른 연주**. 목표에는 실제 앰프·캐비닛·마이크가 섞여 있음.
- 평가 자료: 노브 설정이 알려진 실제 페달 데모 12개(`data/step3_val_data`, TS 3·BD-2 3은 7종에 있음 → 정답 채점, SD-1 3·Klon 계열 3은 7종에 없음 → 계열만).

### 시도와 실패 (정답 있는 실제 데모 6개, 공통 dry = IDMT Strat 프레이즈)

| 방법 | 정답 1위 | 상위 3 | 비고 |
|---|---:|---:|---|
| 기존 거리 d (시점별 스펙트럼) | 0% | 17% | 음·리듬 차이에 반응 |
| 평균 스펙트럼 거리 | 0–50% | 50% | 구간 선택에 따라 크게 흔들림 |
| 평균 스펙트럼 − 완만한 기울기(앰프·마이크 차이 제거) | 0% | 17% | 페달 정보까지 제거됨 |
| 음 단위 비교 (같은 음높이 dry 매칭) | 0% | 33% | 음·타이밍을 맞춰도 실패 → 연주보다 녹음 환경 영향이 큼 |
| 노브 범위 0–100% + 평균 스펙트럼 | 17% | 50% | 자유도↑ → 퍼즈 톤 80%가 모든 목표에 맞춰짐 |
| 목표만 보는 분류기 (자체 CNN, 녹음 환경 무작위화·앰프 크런치) | 0% | 33% | 실제 12개 전부 디스토션·퍼즈로 판단, 합성에서도 33% |

결론: ① 연주 차이와 ② 녹음 환경 차이(특히 앰프 찌그러짐) 모두 원인. dry 없이 목표만으로는 합성에서도 어려움.

## 2. AFx-Rep 도입

AFx-Rep(ST-ITO, ISMIR 2024 공개 모델): 소리 → 512차원 이펙트 지문. 같은 이펙트면 연주가 달라도 지문이 비슷하도록 대량 데이터(VST 프리셋 × 음악·말소리·기타)로 학습됨. 우리 쪽 학습 없이 거리로만 사용.

| 설정 (실제 데모 6개) | 정답 1위 | 상위 3 | 평균 순위 | 계열 일치(12) |
|---|---:|---:|---:|---:|
| AFx-Rep, 2.5초 | 33% | 50% | 3.2 | 50% |
| AFx-Rep, 5.5초(학습 길이) × 여러 구간 평균 | 33% | 67% | 3.0 | 17% |
| **+ 앰프 크런치 후보 (0/6/12 dB)** | **50%** | **83%** | **2.2** | 50% |

- 앰프 크런치: 드라이브 → **최대 음량 기준 tanh 포화** → 캐비닛 IR. (pedalboard `Distortion`은 절대 음량에 반응해 드라이브 뒤 작은 신호에선 거의 안 찌그러짐 → 처음 구현에서 효과가 사라졌던 버그, 수정)
- 정답 있는 합성(다른 연주): `step2_real_v1` 280개를 공통 dry 후보로 채점 → 정답 1위 40.4%, **상위 3 83.2%**, 평균 순위 2.26 (실제 데모와 같은 수준 → 표본 운이 아님)
- 같은 연주 조건: `step2_real_v1` 35개, 각자 원래 dry로 격자만 → **정답 1위 97.1%, 상위 3 100%** (참고: 기존 CNN 단독 65%, CNN + CMA-ES 최종 95.4%)

## 3. Metric hacking: 거리만 줄이고 소리는 안 가까워짐

- 격자 상위 3개를 CMA-ES(AFx-Rep 거리)로 다듬되 **페달도 바꿀 수 있게** 하자 실제 데모 정답 1위 50% → 33%, 5개가 Big Muff로 바뀜.
  → 퍼즈 노브·크런치로 AFx-Rep 숫자만 줄이는 쪽으로 흐름 (최적화 지표가 목표가 되면 지표만 좋아지는 현상).
- 대응
  1. **페달은 격자 순위로 고정, 탐색은 페달 안에서 노브만** (적용)
  2. **dropout 0.1**: 평가마다 지문 일부를 무작위로 빼고 거리 계산 (ST-ITO 원 코드와 같은 방식) – 효과는 5절
  3. **독립 지표로 평가**: 탐색에 쓰지 않은 지표로 채점 (4절)
  4. **결과는 상위 3개 제시 + 청취로 확인**

## 4. 최종 구성 결과 (`outputs/stylematch/step3_v1`, 목표 23개)

구성: AFx-Rep 격자 → 상위 3개 → 페달 안 CMA-ES(예산 30, dropout 없음) → 음량 맞추기.

**독립 지표** (탐색에 안 씀, 목표별 중앙값, 기준선 = 7종 기본 노브 평균)

| 대상 | 스펙트럼 모양 거리 감소 | 기준선보다 나은 비율 | 찌그러짐 통계 거리 감소 | 기준선보다 나은 비율 |
|---|---:|---:|---:|---:|
| 분리 기타 11곡 | 32% | 100% | 80% | 100% |
| 페달 데모 12개 | 20% | 92% | −1% | 50% |
| 전체 23개 | 27% | 96% | 18% | 74% |

- 분리 기타(실제 사용 상황)는 두 지표 모두 전부 개선 → AFx-Rep만 속인 결과가 아님.
- 페달 데모의 찌그러짐 통계는 개선 없음 (1위 페달 기본 노브 8.8 → 보정 후 9.6) → hacking 가능성이 남은 부분.
- 보조 지표(정답 페달 일치, 6개): 1위 50%, 상위 3 83%, 계열 50%.
- 음량 맞추기: 결과 69개(23 × 3) 모두 목표 음량 ±1 dB 이내 (중앙값 0.18 dB).
- 시간: 목표당 약 70–80초 (격자 렌더는 dry별 1회 캐시).

## 5. hacking 대응 효과: dropout 0.1 (페달 데모 12개)

`outputs/stylematch/step3_v1_dropout` vs `step3_v1` (중앙값, 기준 = 1위 페달 기본 노브)

| 지표 | dropout 없음 | dropout 0.1 | 1위 페달 기본 노브 |
|---|---:|---:|---:|
| 스펙트럼 모양 거리 | 5.38 | 5.46 | 6.91 |
| 찌그러짐 통계 거리 | 9.65 | 9.63 | 8.82 |
| 기본 노브보다 나은 목표 (찌그러짐) | 7/12 | 7/12 | – |
| 정답 페달 1위 / 상위 3 | 50% / 83% | 50% / 83% | – |

- **효과 없음.** dropout은 지문 일부만 맞추는 최적화 꼼수를 막는 장치 → 결과가 같으므로 이번 현상은 그런 꼼수가 아님.
- 원인 판단: **AFx-Rep이 찌그러짐 양에 둔감한 지표의 사각지대** (6절: AFx-Rep과 찌그러짐 통계는 서로 다른 것을 잡고, 합치면 신뢰도 최고).
  탐색이 AFx-Rep이 못 보는 찌그러짐 양을 맞출 이유가 없었던 것.
- 대응 후보: 탐색 거리에 찌그러짐 통계를 결합 (단, 그러면 찌그러짐 통계는 독립 평가 지표에서 빠짐).

## 6. 거리 신뢰도

정답 있는 합성 21개(7종 × 3). 목표마다 후보 306개를 "같은 dry로 렌더한 정답 소리와의 실제 거리" 순으로 세운 것과 각 거리의 순위 상관(스피어만, 1 = 완벽).

| 거리 | 평균 상관 | 양(+) 비율 |
|---|---:|---:|
| 평균 스펙트럼 모양 | 0.35 | 86% |
| 찌그러짐 통계 | 0.49 | 100% |
| AFx-Rep | 0.49 (단음만 0.53) | 95% (100%) |
| **AFx-Rep + 찌그러짐 통계** | **0.56** | **100%** |
| AFx-Rep 보정층 (우리 데이터로 분류 학습) | 0.25 | 81% |

- AFx-Rep은 오버드라이브·RAT에서 0.5–0.8, 퍼즈·일부 BD-2·DS-1에서 낮음 → 3절의 퍼즈 쏠림과 일치.
- 보정층 실패 원인: "페달 종류 + 게인·톤"을 맞히는 분류 학습이 같은 페달 안의 미세한 소리 차이와 크런치 차이를 뭉갬 (검증 분류 정확도는 68%로 자체 분류기 36–47%보다 높음).
  필요한 것은 "실제 소리 차이 순서"를 직접 배우는 순위 학습.
- 결론: 거리만으로 1등을 확정할 신뢰도(목표 0.7)는 아님 → **후보 좁히기에 사용, 최종은 상위 3개 + 청취**.

## 7. 공간 리버브 흡수 단계 (옵션 `--room`, 기본 꺼짐)

목표 녹음의 리버브·공간감을 캐비닛 IR 뒤 리버브(pedalboard Reverb, mix 0–0.5 · size 0.2–0.9)로 흡수.
격자에 mix 0 / 0.2 / 0.4 추가 + CMA-ES로 다듬음. 추천 대상 아님.

**합성** (`room_eval.py`, step2_real_v1 다른 연주 28개, 목표에 다른 방식 리버브(감쇠 노이즈 IR) 적용, 격자 판별)

| 목표 리버브 | AFx 거리 변화 | 고른 mix 평균 | 1위 (없음 → 있음) | 상위 3 (없음 → 있음) |
|---|---|---|---|---|
| 없음 | 0 | 0.19 | 46% → 54% | 89% → 89% |
| 약 (RT60 0.6 s) | 0.08 | 0.28 | 43% → 54% | 89% → 82% |
| 강 (RT60 1.5 s) | 0.14 | 0.39 | 46% → 57% | 82% → 86% |

- 리버브 양은 방향대로 따라감, 판별은 나빠지지 않음
- 리버브 없는 목표 28개 중 12개가 최대치(0.4) 선택 → 리버브가 연주 차이를 덮는 데 쓰임 (해킹과 같은 성격)

**실제 23개** (`outputs/stylematch/step3_v1_room`, 기존 `step3_v1`과 비교)

- 1위 페달 23개 중 22개 동일, 정답 있는 6개 1위 50% · 상위 3 83% 그대로
- 독립 지표 개선 없음: 스펙트럼 중앙값 5.08 → 5.43, 목표별로 23개 중 10개만 개선 / 포화 8.14 → 9.12 (리버브가 크레스트 팩터를 낮춰 지표 자체도 영향 받음)
- 리버브 없는 페달 데모에도 mix 0.3–0.4 선택 (BD-2 2개, Archer 1개)

결론: 효과 확인 안 됨 → 옵션으로만 유지, 기본 결과·데모에는 미적용. 공간감은 거리와 분리된 지표(잔향 감쇠 추정 등)로 따로 추정해야 함.

**잔향 따로 추정 시도** (`reverb_est.py`, 가장 빠른 감쇠 속도 dB/s로 mix 결정) → 실패
- 목표 감쇠 속도 중앙값: 리버브 없음 −70 / 약 −62 / 강 −47 dB/s (방향은 맞음)
- 그러나 공통 dry(끊어 치는 프레이즈)는 −150~−300 dB/s, 목표(2.5초 단음 · 코드, 음이 끝까지 울림)는 리버브 없이도 −40~−75 → 84개 전부 최대 mix
- 원인: 2.5초 단음은 음이 끊기는 지점이 없어 자연 서스테인과 잔향을 구분할 수 없음 (지표가 연주 내용에 좌우됨)
- 필요 조건: 음이 끊기는 지점이 있는 긴 목표 구간 + 연주 방식이 비슷한 dry → 향후

**최종: 리버브 게이트** (`match.room_gate`, `--room`일 때만)
- 켜는 조건: AFx 격자 리버브 양 ≥ 0.4 **그리고** 목표 감쇠 속도 ≥ −60 dB/s (둘 중 하나만으로는 오판 많음)
- 합성: 리버브 없음 잘못 켬 18% · 약한 리버브 32% · 강한 리버브 89% (기준을 같은 28개로 정해 낙관적일 수 있음)
- 실제 23개: 켜짐 0개 → 리버브 없는 페달 데모의 오판 3개는 모두 걸러짐, 현재 목표에는 영향 없음
- 리버브 작업은 여기서 종료 (실험용 옵션으로만 유지)

## 8. 한계와 향후

- 정답 있는 실제 녹음 6개 → 수치 변동 큼 (추가 수집 필요)
- AFx-Rep은 기타 드라이브 전용이 아님. 비슷한 오버드라이브(TS · OD-1 · BD-2) 구분 약함, SD-1은 퍼즈·디스토션으로 나옴
- 앰프 크런치는 실제 앰프의 근사. 캐비닛 IR은 1종 고정
- 다른 연주 조건의 컴프·EQ 추정 미지원 (EQ 계산은 같은 연주 쌍 필요)
- 결과는 공통 dry(IDMT Strat)에 대한 설정 → 사용자 기타가 다르면 노브가 달라질 수 있음 (기타별 비교 예정)
- 향후: 순위 학습 기반 거리, 청취 점수 데이터로 거리 보정, 다른 연주 조건 컴프·EQ, 실물 페달 캡처(Step 4)
